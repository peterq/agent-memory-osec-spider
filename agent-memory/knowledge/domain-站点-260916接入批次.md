## 各站要点与坑（开发实测，报告里没有的）

- **duanjuso**：搜索接口 `order` 参数**完全无效**（7 种取值返回相同顺序），无法做水位线早停，只能固定翻页靠关键词 Top-N 机会性覆盖；`size>=60` 被静默降级为 10（缺省取 50）；`share_time=day` 报「索引错误」；`sitemap-index` 里除 `disk-N.xml` 还有 `movie-1.xml`（影片聚合页，需按 URL 含 `/doc/` 过滤）；sitemap 冻结与搜索 `week/month` 之间约 10 天理论空隙。
- **xiaozi**：子 sitemap 数会长（报告 3 个→实测 5 个，不能硬编码）；id 空间不从 1 开始（1~约 26 万全 404，有效 27 万~39 万+）；详情页是 RSC 流式 SSR，正文链接要用 `pinyin:"<id>"` 锚点定位，否则会把「最近上线/相关推荐」区块的链接算进来；「HTTP 200 但找不到锚点」在全量里也会被当空洞 markSeen（≈10 天 TTL），是已知小概率误伤点。
- **qileso**：超界 id 是 **302 到首页**（跟随重定向后才是 200 + 首页标题），客户端不能关重定向；短时间连续直连会 **429**（阈值未定量）；并发 1 只有 3.5 条/分钟，并发 2 才 14.8。
- **jsnoteclub**：每篇文章固定嵌 2~3 条全站模板链接（下载引导/电子书合集），会造成下游 `ErrDupTask`，因此去重改成「抓取解析成功即按 路径+lastmod 标记已见」，与 fuxipan/kuakes 的「提交失败不标记」不同；文章 lastmod 变化会重新处理。
- **ddys**：反爬（非代理出口 403），代理经常 EOF/超时，退避 3/6/12/24 s 最多 5 次尝试；`movies-1.xml` 按 lastmod **降序**（新在前），`movies-2.xml` 是冻结的历史导入批次（lastmod 恒 2026-03-02）；「失败不标记已见」无显式上限，靠 240 h 全量周期 + 100 条增量窗口限流。

## 本批共同约定（在 2609 批次基础上新增）

- 联网测试与 probe **必须走代理池**：测试 `NeedDirect:false` + `proxy_provider.OnProxyWith` 订阅，等不到代理 `t.Skip`；probe 复用 COMMON `site-discovery/tools/{httputil,proxypool}.py`，拿不到代理退出码 3，不留 `--no-proxy`。本地跑要 `LOCAL_CONFIG_PATH=<worktree>/config.local.yaml`（gitignore，指向本地 redis db2 的 `proxy_subject`）。
- 断言按下限/比例，不要求 100% 成功（本地代理池薄）。
- `bnd/ali-share/xunleipan` 在多站样本零命中，代码有支持但未端到端验证。
