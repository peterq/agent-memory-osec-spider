# 决策：搜索 p90 告警关闭匿名搜索 + 两个总览页的数据源口径

## 背景
用户 2026-09-16 要求：①「分享链接总览」按时间段/类型看新增（按来源）、检测数、检测有无更新、失效数；②「搜索总览」主要用 SLS 日志实现（搜索量/延迟/IP 数/用户数/Top10 IP、uid/Top1000 搜索词），并对 p90 报警且关闭匿名搜索 30 分钟。任务简报：`agent-tasks/2026-09-16-share-search-overview/`。

## 要解决的问题
- 搜索监控数据只在 SLS，网关如何聚合；SLS `data` 字段是否开启统计不可知（主控探针被 auto 模式分类器拦截）。
- 关闭匿名搜索需要跨进程（网关判定 → API 执行）。
- 分享链接的「检测数」没有逐次事件表，「来源」不在 res_lc 分表里。

## 备选方案
| 方案 | 优点 | 缺点 |
|---|---|---|
| A. API 自己算 p90 并关闭（进程内滑窗，同 search_canary） | 无外部依赖 | 两台 API 各算各的、后台无法统一看/调参；与"用 SLS"要求不符 |
| B. 网关 leader 查 SLS，结果写共享 redis，API 读键拦截 [采用] | 单点判定、后台可看可调、API 改动极小、fail-open 安全 | 依赖 SLS 可用；SQL 未开启需降级 |
| 检测数：新增逐次事件行 | 精确 | 每天百万级插入，不可接受 |
| 检测数：redis 按类型小时/天桶计数器 [采用] | 便宜、够用 | 只有上线后的数据 |
| 来源：给 64 张分表加 client 列 | 历史可回填 | 改表贵；ES 已有 client 字段 [采用 ES 聚合] |

## 最终决策
1. **契约**（COMMON `f2f0881`）：`LifecycleRpc.ShareOverview`；新 `SearchAdminRpc`（Overview/Top/GuardStatus/SetAnonymous/UpdateGuardParams）。
2. **搜索总览**：网关新模块 `services/gateway/search_admin`，查 API logstore `resource-backend`（`service:resource-search-api and (stage:search or stage:search-v3)`），SQL 优先，探测失败降级为拉原始日志（上限 `max_scan_lines`，响应 `source=sls-scan`/`truncated` 如实标注）。
3. **防护**：网关 leader 每 60s 查最近 5 分钟 p90；`p90>3000ms` 连续 2 次且样本 ≥30 → 邮件（source `search-guard`，去抖 30 分钟）+ `SET search_guard:anonymous_closed <json> EX 1800`。参数在 redis hash `search_guard:params` 热更新，后台可手动关/开。API 两个搜索入口对 `uid=anonymous` 读到键即返回 403/50008「请登陆后再搜索」，redis 出错 **fail-open**。
4. **redis 键约定**（API 与网关同一实例 db 6）：`search_guard:anonymous_closed`（JSON reason/by/closedAtMs/untilMs，TTL=关闭时长，无键=开放）、`search_guard:params`、`search_guard:state`、`search_guard:events`（list ≤200）、`search_guard:leader`。
5. **分享链接总览口径**：created/updated/invalid/moved/legacy_invalid_hint 来自 `res_lc_event` 按桶 GROUP BY（updated = 再爬发现 version 变化 = "检测有更新"）；checked/valid/invalid/error 来自新的按类型计数器 `resLc:cnth:<name>:<type>:YYYYMMDDHH`（35 天）/`resLc:cntd:<name>:<type>:YYYYMMDD`（400 天），起算时间记 `resLc:cnt:since`；新增按来源 = ES `client` terms（ctime 区间），与事件 created 并列展示不做对账；存量 = `Stats()` 缓存快照。

## 决策原因
不新增进程（沿用「管理类并入网关」）；判定单点化、可观测、可调参；API 只加一次 redis GET（1s 本地缓存），最坏情况放行而非误伤。

## 影响
- 网关需部署到 res1/res2；API 需部署；前端新增 4 页（分享链接总览、搜索总览、搜索词 Top1000、匿名搜索防护）。
- 若 SLS 未开启 `data` 字段统计，需在控制台为 `resource-backend` logstore 开 JSON 索引+统计，否则长期处于降级扫描。

## 复盘条件
- 防护误触发（p90 因 ES 抖动短暂升高即关匿名）→ 调高 sustain/threshold 或 autoClose=false。
- 计数器 400 天天桶键量（3×4×400≈4.8k）若影响 redis，缩短 TTL。
