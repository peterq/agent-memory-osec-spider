# 用户偏好与协作约定

## 已确认的硬性要求（来自仓库根 `AGENTS.md`）

1. **语言**：向用户展示的信息用中文；Agent Memory 用中文；代码注释用中文。
2. **脚本沉淀**：为完成任务写的脚本，只要有复用价值就落盘进仓库并写文档；后续调用时用项目内路径调用，避免把脚本内容重复输出到对话里浪费 token。
3. **记忆体系**：必须按 `AGENTS.md` 内嵌的 `agent-memory` 技能定义工作，严格遵循其"第 15 节 自主进化循环"。
4. **thinking 控制**：开启思考模式时，thinking 只写主要思路和核心要点，不要和正文大量重复。
6. **[用户确认 2026-09-04] 子 Agent 模型与分工**：编码、验收、合并这类执行性工作都派 **sonnet** 子 Agent
   （"尽量使用便宜但满足需求的模型"），主会话只负责规划、写规格、审查结果、把控全局。
   并发上限按用户当次指定（本次"最多 6 个"）。
7. **[用户确认 2026-09-08] 子 Agent 任务描述必须落盘**：派子 Agent 时不要把长篇任务描述重复写进
   每个 prompt——共享上下文写进 `agent-tasks/<日期>-<任务名>/00-shared.md`，各角色专属内容写进
   `10-*.md` / `90-review.md`，prompt 只给绝对路径让子 Agent 自己读。追加要求改文件而不是复述。
   理由：多个子 Agent 之间重复内容会让主控上下文线性膨胀，且历史消息里的上下文无法跨会话复用。
   做法见 `procedures/workflow-子agent任务简报.md`，模板正本 `agent-tasks/README.md`。
8. **[用户确认 2026-09-04] 任务完成后 commit 并 push**（代码与 COMMON 记忆都算），不再停在"本地提交留给用户 push"。
   上线类任务 push 是第一步。被安全策略拦截时明确告知哪些没推。
9. **[用户确认 2026-09-12] 禁止使用 harness 记忆**（Claude Code 自带的 `~/.claude/projects/*/memory/`），本项目一切记忆只写 `agent-memory/`。
   原先 harness 记忆里的偏好（sonnet 子 Agent、commit+push、任务简报落盘、配置拆代码、部署放行规则）均已在本文件与 `procedures/workflow-部署.md` 中，harness 目录已清空。
10. **敏感信息禁止入记忆**：配置文件（`config*.yaml`、`deploy.sh`、`_note/config/*`）里含明文阿里云 AK/SK、
    S3 凭证、ES/MySQL/Redis 账号口令，**禁止写入任何记忆文件、任务简报或对外输出**，只记录文件路径；
    需要展示配置结构时手工脱敏。风险详情见 `current/risks.md` R2。

## 推断的工作习惯（未经用户确认，标记为推断）

- 用户是该系统的主要维护者（git 作者 `peterq <me@peterq.cn>`），对四个仓库都有完整上下文，不需要基础科普。

## 注意事项

- 规则**只有一份正本**：记忆仓库根的 `AGENTS.md`； `CLAUDE.md` 是指向它的**软链接**。改规则只改正本。

## 配置设计原则（[用户确认 2026-09-08]）

- **不要把所有服务的配置放在一份文件里**：config 具有按键自动注入依赖的功能，统一文件会让每个进程被注入它不依赖的东西；网关进程里再注入网关客户端（指向自己）没有意义，甚至可能引发循环。**[用户澄清 2026-09-09 07:08，另一会话]「按服务拆分」指拆代码不是拆文件**：角色包 + 惰性 Get，配置文件保持一份；**[用户 2026-09-09 11:10] 去掉构建 tag**——按 tag 区分服务会让 spider 二进制无法复用、需为每个服务单独构建，不可取；保持单一二进制，角色由运行时所选子命令决定，隔离靠静态 import 门禁 + loader 运行时"一进程一角色"保护；09-08 按"两份文件"理解做的 `4d7fc5b`/`7c05d00` 从未上线、已于 09-09 回退（SPIDER `4f5f528`）。

## 配置隔离的原则（[用户确认 2026-09-09]）

- "配置按服务拆分"= 拆**代码**：每个进程角色有自己的根配置结构体与 `Get()`（按 package 隔离 +
  构建 tag 保证），section 结构体共享、组合不共享；**禁止导出 `config.Config` 全局变量**，
  初始化从 `init()` 移入 `Get()`。
- 配置**文件尽量只有一份**，减少维护成本；隔离靠类型（进程根本没有那个字段），
  不靠"文件里不写某项"来避免自动注入，也不靠运行时断言当护栏。
- 见 `decisions/decision-2026-09-09-配置按进程拆代码而非文件.md`。
