## 关键发现
- 品牌版 Chrome 153：`--load-extension` 连 feature 开关也无效；策略强装需去掉 `--disable-background-networking`、加 `override_update_url`、用 `developerPrivate.autoUpdate` 触发升级。
- NFS：445 文件 cp 31 s → 单 tar 1~2 s；组件更新器让 profile 膨胀到 86 MB → 只打包 Default/+Local State + `--disable-component-update`。
- **FC 断开 WebSocket 即冻结实例**：断开后的写回不执行（锁心跳停滞、2 分钟无 tar）。
- SIGTERM 关 Chrome 会丢 localStorage 最后几秒的写入，Browser.close 不丢。
- `s info/deploy` 的 ConnectTimeout 与本机到 FC 域名的 `198.18.x.x i/o timeout` 都是本机代理抖动，重试即可。

## 决策
- `decisions/decision-2026-09-13-cdp3持久化会话与扩展机制.md`（临时目录用第二挂载点、VPC 照抄 image-render、profile 单 tar、连接内写回、锁 90 s 过期、定时 04:30 清 >24 h）。
