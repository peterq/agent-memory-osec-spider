## 踩到的坑（都已写进报告）

1. **`deploy.sh` 的 `docker rm -f` 静默失败又复现**：res2 上该步 ssh `Connection timed out`
   被 `|| true` 吞掉 → `docker run` 报容器名冲突 → 二进制换了容器没换。
   靠"部署后必看 `docker inspect -f '{{.Created}}'`"这条既有记忆当场发现。
2. **新索引里 `type` 是 keyword 本体，没有 `.keyword` 子字段**（旧索引才有）。
   用 `type.keyword` 聚合返回空桶，一度误判"百度型 join 没注入"。
3. **`_cat/indices` 的 `docs.count` 包含 nested 子文档**。
   6,584,361 里只有 728,767 个 `resource` + 1,369,327 个 `file`，
   余下约 449 万是百度资源 `nested filelist` 的隐藏 Lucene doc。按 `join` 聚合才是真实结构。
4. **API v2 的端口是 8083**（`api-starter`），不是 8080；8085 也回 200 但 3 ms 返回，不是查询路径。
5. `pkill -f '<模式>'` / `pgrep` 在 Bash 工具里会匹配到自己所在的 shell 命令行并把它杀掉
   （表现为 exit 144）。要么改用 `pgrep -af` 先看再按 pid kill，要么让模式避开自身。
