## 关键发现（可复用）

- **[事实] `lifecycle_init_indexes` 自带 `PutTemplates`**，不需要人工 `PUT _template`；模板名以代码为准：
  `res_lc_short_tpl`（pattern `res_short_*`）/ `res_lc_long_tpl`（`res_long_*`），`order=100` 用来压过阿里云默认模板。
- **[事实] 该子命令按设计建 3 个索引**（含空的上月 `res_short_202608` 挂 `res_lc_prev`），不是 2 个。
- **[事实] gorm `AutoMigrate` 不写表注释与索引注释**，列注释里的英文引号/分号会被转义丢弃。
  比对 DDL 时只应逐列比类型/默认值/可空性/索引，注释差异属正常。
- **[事实] 子命令跑 job 时用内存态 job（id=0）**，日志会刷 `record not found ... res_lc_job WHERE id = 0`，属正常。
- **[事实] 本机 → osec-res1 scp 一个 60MB Go 二进制约需 25 分钟（≈40KB/s）**。
  部署网关要预留这段时间，必要时先 `strip`。
- **[事实] 生产 ES 是阿里云 6.7.0**，`_cat/indices` 不认 `expand_wildcards` 参数（会 400）。
- 线上 `mysql` 客户端在 osec-res1（`/usr/bin/mysql`）；网关 DSN 口令含 `!@#`，按 `@tcp(` 切分才切得对，
  且 DSN 里**没有端口**（默认 3306）。
